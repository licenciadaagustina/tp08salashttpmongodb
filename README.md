# TP N°08: CRUD de Salas con Node.js, Express y MongoDB

Proyecto desarrollado para la gestión de reservas de salas, implementando una API REST completa y una interfaz web con vistas EJS, conectado a una base de datos MongoDB Atlas. Trabajo práctico enfocado en seguridad, robustez, manejo de datos y control de errores.

## 🚀 Tecnologías y Herramientas Utilizadas
- **Node.js** y **Express** (Entorno de ejecución y framework backend)
- **MongoDB** y **Mongoose** (Base de datos NoSQL y ODM)
- **EJS** (Motor de plantillas para la interfaz web)
- **Dotenv** (Gestión segura de variables de entorno)
- **Git y GitHub** (Control de versiones)
